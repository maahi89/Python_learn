1️⃣ Activate Virtual Environment

Open the folder containing .venv

Example:
C:\Users\mahit\OneDrive\Desktop\Learn_python

Command:
>> .\.venv\Scripts\activate

Deactivate venv:
>> deactivate


2️⃣ Connect to MySQL Database

Start MySQL session:
>> \sql

If connection fails or session disconnects:
>> \connect root@localhost

3️⃣ Run the Project

Set terminal path to project folder

Example:
C:\Users\mahit\OneDrive\Desktop\Learn_python\Python Projects\Employee_API\employee

Run the project from main file:
>> uvicorn main:app --reload


4️⃣ Check API

Default API:
>> http://localhost:8000/

Check endpoint:
>> http://localhost:8000/employee/id

Swagger API docs:
>> http://localhost:8000/docs
